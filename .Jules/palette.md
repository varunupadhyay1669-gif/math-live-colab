## 2024-05-06 - Input Accessibility & Icon Buttons
**Learning:** We observed that inputs across the application (like in `Home.tsx`) frequently rely exclusively on `placeholder` attributes without an associated `<label>` or `aria-label`. This pattern is inaccessible for screen readers. Furthermore, while the custom `data-tip` provides visual tooltips on hover for icon-only buttons (like in `Room.tsx` and `StudentView.tsx`), it does not automatically map to screen reader properties, meaning these buttons remain unlabelled for assistive technology.
**Action:** When designing new forms, always explicitly include either a visual `<label>` with an `htmlFor` attribute or an `aria-label` attribute on the `<input>`, rather than relying on placeholders. For all icon-only buttons relying on `data-tip` tooltips, duplicate the label into an explicitly defined `aria-label` attribute on the button element to ensure keyboard and screen reader accessibility.
